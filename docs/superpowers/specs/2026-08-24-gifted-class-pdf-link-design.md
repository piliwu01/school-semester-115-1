# 資優班區塊 PDF 連結設計規格

## 目標

在「嘉義市立北興國中 115 學年度第一學期 班/師課表」主標題下方加入資優班區塊課表連結，讓教師能明確找到附件，並在不離開主課表的情況下開啟 PDF。

## 來源檔案

- 使用者提供的 PDF：`115-1-資優班區塊.pdf`
- PDF 共 11 頁且未加密。
- 原始 PDF 保持不變；網站使用專案內的複本。

## 版面與文字

- 連結放在主標題正下方、搜尋列上方。
- 採用符合現有馬卡龍風格的圓角按鈕卡片。
- 使用淡紫與薄荷色系，並保留足夠文字對比。
- 顯示 PDF 圖示及文字：「開啟 115-1 資優班區塊課表（PDF）」。
- 桌機版維持與主內容相同的最大寬度；手機版寬度自動縮放，不造成額外水平溢位。

## 連結行為

- 點擊後以新分頁或新視窗開啟 PDF。
- 連結使用 `target="_blank"`。
- 連結同時使用 `rel="noopener noreferrer"`，避免新頁面控制原課表頁。
- PDF 存放於網站的 `assets` 資料夾，使用穩定的相對路徑連結。

## 不在本次範圍

- 不修改 PDF 內容。
- 不把 PDF 直接嵌入課表頁面。
- 不改動課表資料、搜尋行為、教師／班級目錄或既有配色規則。
- 不公開發布，也不變動舊暑輔網站。

## 驗證標準

1. 連結文字與位置正確。
2. PDF 複本與原檔的 SHA-256 雜湊值一致。
3. 連結目標存在，並包含 `target="_blank"` 與 `rel="noopener noreferrer"`。
4. 點擊連結後 PDF 可在新分頁或新視窗開啟。
5. 桌機與手機版面正常，連結卡片不造成額外水平溢位。
6. 原始 HTML、原始 PDF 與舊暑輔網站均未被修改。
