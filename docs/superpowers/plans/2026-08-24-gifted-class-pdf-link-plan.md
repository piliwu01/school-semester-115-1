# 資優班區塊 PDF 連結實作計畫

## 目標

依照已確認的設計，在新版課表主標題下方加入「開啟 115-1 資優班區塊課表（PDF）」馬卡龍連結卡片。點擊後以新分頁或新視窗開啟專案內的 PDF 複本。

## 執行步驟

1. 建立 `assets` 資料夾，將原始 PDF 複製為 `assets/115-1-gifted-class-block.pdf`。
2. 比對原檔與複本的 SHA-256 雜湊值，確認 PDF 內容完全一致。
3. 在產生器加入 PDF 連結卡片的 HTML 與馬卡龍樣式。
4. 將連結卡片插入主標題下方、搜尋列上方。
5. 設定相對連結、`target="_blank"` 與 `rel="noopener noreferrer"`。
6. 更新自動驗證，檢查連結文字、路徑、位置及新視窗安全屬性。
7. 重新產生 `index.html`，執行既有課表資料與連結完整性驗證。
8. 用桌機與手機尺寸檢查卡片位置、文字對比及版面寬度。
9. 實際點擊連結，確認 PDF 在新分頁或新視窗開啟。
10. 回報本機預覽結果；不推送 GitHub，不變動舊暑輔網站。
